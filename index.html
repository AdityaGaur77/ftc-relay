Relay runs through our nonprofit, so mentoring can count as volunteer service. It's capped, and every call has to be recorded so we can sign off on it honestly.

how hours work —

  1. Tell the team the call is being recorded.
  2. Hit record before you start talking.
  3. Log the session with the recording link.
  4. We review it, then it's approved.
